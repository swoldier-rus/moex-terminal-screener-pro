# MOEX T-Bank Terminal Screener Pro

[![Version](https://img.shields.io/badge/version-17.15-blue.svg)](moex_screener.user.js)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/platform-Tampermonkey%20%7C%20Violentmonkey-orange.svg)](#установка)

> **MOEX T-Bank Terminal Screener Pro** — высокопроизводительный встраиваемый скринер акций Московской Биржи (MOEX TQBR) для веб-терминала Т-Банка (Т-Инвестиции). Выполняет непрерывный мульти-таймфреймовый технический анализ (5m, 15m, 1h, 4h), рассчитывает относительные объемы (RVOL), детектирует кульминации рынка и мгновенно переключает графики терминала через React Fiber.

---

## 🚀 Основные возможности

### 📊 Мульти-таймфреймовый анализ (0 сек задержки)
* **Одновременный мониторинг 4 таймфреймов:** `5 минут`, `15 минут`, `1 час`, `4 часа`.
* **Классический RSI по Уайлдеру (RMA):** расчет перепроданности ($\le 30$) и перекупленности ($\ge 70$).
* **Сглаженный Slow Stochastic (14, 3, 3):** сигналы %K и %D в зонах экстремумов ($\le 20$ / $\ge 80$).
* **Относительный объем (RVOL 10d):** сопоставление текущего дневного объема со средней нормой за последние $N$ торговых сессий.
* **Детектор кульминаций (Climax Volume):** автоматическое выявление точек капитуляции продавцов (`КАПИТУЛЯЦИЯ`) и эйфории покупателей (`ЭЙФОРИЯ`) при всплесках объема $\ge 2.0x$.

### ⚡ Нативная интеграция с Терминалом Т-Банка
* **Интеграция кнопки в верхнюю панель терминала:** нативная иконка скринера в шапке сайта рядом с кнопкой *«Виджеты»*.
* **Мгновенное переключение графиков (React Fiber Bridge):** клик по строке тикера в таблице моментально переключает целевой график терминала без перезагрузки страницы и без использования поля поиска.
* **Поддержка 4 цветовых групп терминала:** автоматический выбор или привязка к определенной цветовой группе (🟡 Желтая, 🔴 Красная, 🟣 Фиолетовая, 🔵 Голубая).
* **Плавающее окно с Drag & Drop и Resize:** свободное перемещение за шапку и масштабирование за правый нижний угол с сохранением координат.

### 🔔 Мульти-канальная система оповещений
* **Синтезированный Web Audio звук:** высокоточный звуковой сигнал без внешних файлов (различная тональность для Long, Short и Climax).
* **Системные Push-уведомления:** всплывающие уведомления Windows/macOS.
* **Telegram-бот:** прямая отправка сигналов в ваш Telegram-чат с тикером, ценой, RSI, Stoch и RVOL.
* **Антиспам Cooldown:** таймер тишины по каждому инструменту (5–60 минут) с визуальным таймером `⏳Xм` в таблице.

### ⚙️ Эргономичное окно настроек (3 модуля)
1. **Сигналы & Анализ:** настройка периодов индикаторов, симметричных порогов и минимального дневного оборота (фильтр ликвидности).
2. **Оповещения:** тумблеры звука, Push и Telegram с кнопками мгновенного тестирования.
3. **Система & Списки:** управление токеном Т-Инвестиций, частотой опроса и удобный менеджер Избранного (чипсы с быстрым добавлением тикеров через запятую).

## 📦 Установка

1. Установите расширение **[Tampermonkey](https://www.tampermonkey.net/)** (или Violentmonkey) для вашего браузера (Chrome, Edge, Яндекс.Браузер, Firefox).
2. Создайте новый скрипт в Tampermonkey и скопируйте содержимое файла **[`moex_screener.user.js`](moex_screener.user.js)**.
3. Сохраните скрипт (<kbd>Ctrl</kbd> + <kbd>S</kbd>).
4. Откройте терминал Т-Банка: **[tbank.ru/terminal/](https://www.tbank.ru/terminal/)**.
5. В правом верхнем углу терминала (перед кнопкой *«Виджеты»*) появится кнопка вызова скринера.

## 🔑 Настройка API Т-Инвестиций

Для расчета реальных индикаторов с нулевой задержкой требуется токен T-Invest API (только чтение):

1. Перейдите в **Настройки профиля Т-Инвестиций** → **Токены T-Invest API**.
2. Выпустите токен с правами **«Только чтение»**.
3. В окне скринера нажмите иконку **⚙️** (Настройки) → вкладка **«Система & Списки»**.
4. Вставьте токен в поле *«Токен Т-Инвестиций»* и нажмите **«Сохранить токен»**.

> **Безопасность:** Токен хранится исключительно в локальном защищенном хранилище Tampermonkey вашего браузера (`GM_setValue`) и используется только для прямых запросов к официальному API `invest-public-api.tinkoff.ru`.
